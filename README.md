## Project Info
This is a project designed to showcase the technologies I used.  
Everything is fictional and intended only for demonstration purposes.


## Description
A real estate listing website. It supports user registration and the ability to add properties to "favorites".  
Create, Edit, Delete listing with authorization verification.
